Lab 1: C# Basics

C# First Lab

This lab is an introduction to C# for students who have previously programmed in Java.

The aim is not to learn everything about C#. Instead, we will look at some of the basic syntax you will need for the rest of this module.

Note: We will not read from the console or from files in this lab. So we will not use Console.ReadLine(). The applications developed later in this module will use graphical user interfaces rather than reading input from the console. We will deal with file reading/writing later.

Part 4 - Formatted Output

Java programmers may be familiar with printf() for producing formatted output.

For example:

System.out.printf("Name: %s, Age: %d%n", name, age);

C# provides several ways of producing formatted output. One of the simplest is string interpolation.

Place a $ before the string and put variables inside { }:

Console.WriteLine($"Name: {name}, Age: {age}");

The values of the variables are inserted into the string.

Exercise

  • a student’s name
  • their age
  • their average mark

For example:

Alice is 21 years old and has an average mark of 68.

Remember: String interpolation is an alternative to string concatenation. You can still use + when appropriate.

Formatting Values

String interpolation can also be used to control how a value is displayed.

For example, a double can be displayed to two decimal places using F2:

double doubleNumber = 3.14159265359;

Console.WriteLine($"Pi rounded is : {doubleNumber:F2}");

This produces:

Pi rounded is : 3.14

The F2 means fixed-point notation with 2 decimal places.

The same formatting can be used with ToString():

Console.WriteLine(doubleNumber.ToString("F2"));

This produces:

3.14

ToString() is available on all objects in C#. It provides a string representation of the object or value.

For example:

int number = 42;

Console.WriteLine(number.ToString());

produces:

42

We can also provide a format when converting a value to a string, as with doubleNumber.ToString("F2").

You can find the other standard numeric formatting options in the Microsoft documentation:

Standard numeric format strings - Microsoft Learn

Ternary Conditional Operator

C# also provides a shorthand way of writing a simple if/else when we want to choose between two values.

The syntax is:

condition ? valueIfTrue : valueIfFalse

For example:

int number = 7;

string result = number % 2 == 0 ? "Even" : "Odd";

Console.WriteLine(result);

The condition is checked first. If it is true, the first value is used; otherwise, the second value is used.

The above is equivalent to:

if (number % 2 == 0)
{
    result = "Even";
}
else
{
    result = "Odd";
}

Part 9 - The Animal Class

Create a class called Animal.

The class should contain:

  • a private _name field of type string
  • a private _age field of type int
  • a public Name property
  • a public Age property
  • a constructor that sets the name and age

What is a field/property? Java Version? Why?

I will talk about this more in lectures but in java, for proper encapsulation, you typically did

private int age;

public void setAge(int age){
  this.age = age;
}

public int getAge(){
  return age;
}

In C#, this approach will work fine, but it is not typically how we provide access to fields. Instead, C# provides properties.

private int _age;

public int Age
{
    get { return _age; }
    set { _age = value; }
}

The property allows us to control how the value can be accessed or changed.

One advantage is that we do not have to explicitly call setAge and getAge. We can treat the property much like a variable:

dog.Age = 5;
Console.WriteLine(dog.Age)

The get code runs when we read the property, while the set code runs when we assign a value to it.

The special keyword value represents the value being assigned to the property.

Naming Convention

In this module we will use the following naming convention:

  • Private fields begin with _ and use lowercase/camelCase:
    • _name
    • _age
    • _breed
  • Public properties and methods begin with a capital letter:
    • Name
    • Age
    • Sound()

Part 11 - Sound() Method

In the Animal base class, create a method called Sound.

The Sound() method should display:

This animal makes a sound

In Java, you can override an inherited method simply by providing a new implementation in the derived class (with @Override used to indicate that this is intentional).

C# is a little different. A method must explicitly allow itself to be overridden. To do this, the base-class method is marked virtual:

public virtual void MakeSound()
{
    Console.WriteLine("Some sound");
}

A derived class can then provide its own implementation using override:

public override void MakeSound()
{
    Console.WriteLine("Woof!");
}

Think of it as:

Java asks for forgiveness; C# asks for permission. And it’s easier to ask for forgiveness.

So, in C#, virtual is essentially the base class saying:

“Derived classes are allowed to replace this method with their own implementation.”

If a method is not marked virtual (or abstract), a derived class cannot override it.

So now:

Override the Sound() method in Dog.

It should display:

Woof!

Taking into consideration what was written above.

Part 15 - ToString on Object

Every C# object has a (virtual) ToString() method.

You can use it directly:

Console.WriteLine(animal.ToString());

or, because Console.WriteLine() can work with objects, try:

Console.WriteLine(animal);

Both approaches will use the object’s ToString() method.

We can override it in our own class to provide a useful description of the object.

Override ToString() so that an Animal produces a string containing its name and age.

For example, an animal named Rex aged 5 might produce:

Rex is 5 years old

You could then override it again in the Dog class to say

Rex the dog is 5 years old
