Lab 4 — Whack-a-Mole

Aim

In this lab you will build a simple Whack-a-Mole game using .NET MAUI.

You will bring together:

  • XAML layouts
  • Runtime modification of a Grid
  • Border
  • Events
  • TapGestureRecognizer
  • DispatcherTimer
  • async and await
  • .NET MAUI animations

The finished game will have a 3 × 3 grid. A mole will appear in a random cell and the player must tap it before it disappears.

Compile and run regularly as you work.

1. Create the Project

Create a new .NET MAUI App project.

Use:

  • Framework: .NET 10.0
  • Project name: WhackAMole

Run the application before making any changes.

Open MainPage.xaml.

Replace the contents inside your existing page with the following:

4. Game Fields

We need to keep track of three things.

We need 3 fields:

  • _score — int
  • _timeRemaining — int
  • _gameTimer — IDispatcherTimer

Create these fields in your class.

Start the first two at appropriate initial values.

For example, the score should start at 0 and the game should last 30 seconds.

Add the columns

Now add another loop to add three ColumnDefinitions.

Add the cells

Use nested loops to create a Border for every cell.

Use a Border with a more interesting appearance, for example:

Border border = new Border
{
    BackgroundColor = Colors.LightGreen,
    Stroke = Colors.DarkGreen,
    StrokeThickness = 3,
    StrokeShape = new RoundRectangle
    {
        CornerRadius = 15
    },
    Margin = new Thickness(5)

Add each Border to the correct position using the overloaded Add() method:

GameGrid.Children.Add(
    border,
    column,
    row);

Remember that this is:

column, row

Do not use Grid.SetRow() or Grid.SetColumn().

7. Make the Mole Tappable

We only need the mole to respond to taps.

We do not need to add a TapGestureRecognizer to every cell.

Create a TapGestureRecognizer for the existing Mole and connect its Tapped event to a method called:

OnMoleTapped

Add the gesture recognizer to the mole.

Your event handler should have a signature similar to:

private void OnMoleTapped(
    object? sender,
    TappedEventArgs e)
{
    
}

When the mole is tapped:

  1. Increase _score.
  2. Update ScoreLabel.
  3. Move the mole to a new random position.

There is no need for a “miss” counter.

If the player taps somewhere that does not contain the mole, nothing happens.

8. Add the Game Timer

Now we want the mole to move automatically.

Create the IDispatcherTimer using:

_gameTimer = Dispatcher.CreateTimer();

Set an appropriate interval and connect the Tick event.

The timer should call MoveMole() each time it ticks.

Start the timer when the game starts.

Remember that we already used DispatcherTimer in the previous lab.

9. Countdown

Use _timeRemaining to keep track of how long the game has left.

Each time the timer ticks:

_timeRemaining

should decrease by one.

Update:

TimeLabel

so that the player can see the remaining time.

When the time reaches zero:

  • Stop the game timer.
  • Re-enable the Start button.
  • Leave the final score visible.

10. Start the Game

Now complete StartGame_Clicked.

When the button is pressed:

  1. Reset _score.
  2. Reset _timeRemaining to 30.
  3. Update the score and time labels.
  4. Create the game grid.
  5. Move the mole to its first random position.
  6. Start the timer.
  7. Disable the Start button.

You may want to put some of this work into a separate StartGame() method rather than putting everything into the button event.

11. Make the Mole Disappear

At the moment, the mole could stay visible in one cell until the next timer tick.

Instead, we want the mole to disappear if the player takes too long to hit it.

We can use an animation for this.

For example:

await Mole.FadeToAsync(
    0,
    500);

This fades the mole to an opacity of 0 over half a second.

The useful thing about this is that the animation itself takes time.

We can therefore use the fade as the mole’s “time limit”, rather than creating another timer.

Make the method that controls the mole movement asynchronous.

For example:

private async Task ShowMole()
{
    
}

The method should:

  1. Move the mole.
  2. Make sure it is visible.
  3. Wait while it is displayed.
  4. Fade it away.
  5. Move it to a new position.
  6. Show it again.

Think about how await allows the UI to remain responsive while the animation is running.

12. What Happens When the Mole Is Hit?

There is now an interesting problem.

Suppose the mole is currently fading away and the player taps it.

We do not want the old fade animation to continue while we move the mole.

.NET MAUI provides:

Mole.CancelAnimations();

This cancels animations currently running on that element.

Use this when the mole is successfully tapped.

The basic sequence becomes:

Player taps mole
      |
      v
Cancel current animation
      |
      v
Increase score
      |
      v
Move mole
      |
      v
Show mole again

This means we can have one game timer, rather than creating another timer just to control how long the mole remains visible.

13. Animation

Make the mole appear smoothly.

For example, after moving it, start with:

Mole.Opacity = 0;

and then use:

await Mole.FadeToAsync(
    1,
    200);

You could also experiment with ScaleToAsync().

For example:

await Mole.ScaleToAsync(
    1,
    200);

Try making the mole start slightly smaller and grow into place.

Remember that these animation methods are asynchronous, so you will need await.

14. Finishing the Game

When the countdown reaches zero:

Game Over!
Score: 12

The mole should no longer respond to taps.

The timer should stop.

The Start button should become available again.

Think about what needs to happen to the mole’s current animation when the game ends.

You can use:

Mole.CancelAnimations();

to stop an animation that is currently running.

15. Improve the Game

Once the basic game works, improve its appearance.

Try changing:

  • The colours of the cells
  • The mole
  • The title
  • The score and timer
  • The Start Game button
  • The animation
  • The speed of the mole

You could also make the game progressively harder by making the mole disappear more quickly.

For example:

Early game       Mole stays longer

Middle game      Mole stays for less time

Late game        Mole disappears quickly

Think about how you could change the duration of the fade animation based on the remaining time.

Final Requirements

Your completed application should:

  • Run as a .NET MAUI application.
  • Target .NET 10.0.
  • Start with the Grid defined in XAML.
  • Start with the mole defined in XAML.
  • Dynamically add a 3 × 3 set of Borders to the existing Grid.
  • Move the existing mole between cells.
  • Use TapGestureRecognizer.
  • Keep track of the score.
  • Have a 30-second countdown.
  • Use DispatcherTimer.
  • Move the mole automatically.
  • Make the mole disappear if it is not tapped.
  • Use .NET MAUI animations.
  • Use async / await.
  • Allow a new game to be started after the current game finishes.

Make sure the basic game works before spending time on visual improvements or additional features.
