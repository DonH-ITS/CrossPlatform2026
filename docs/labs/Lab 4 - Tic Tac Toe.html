The Game Board

A normal Tic Tac Toe game has a 3 × 3 board.

In the previous lab, you created Grids and placed controls into individual cells using XAML. At the end of a previous lab (Lab 2) I had you create a 3x3 grid using XAML. We are basically going to recreate that, but this time using C#.

We are going to create the contents of the board while the application is running using C#.

This is useful when the number of controls is not known in advance.

For example, if a user could choose a 3 × 3, 4 × 4 or 5 × 5 board, we would not want to manually create every possible square in XAML.

Create a Placeholder Grid

Add the following Grid to your XAML:

<Grid x:Name="GameGrid"
      BackgroundColor="CornflowerBlue"
      HeightRequest="300"
      WidthRequest="300"
      HorizontalOptions="Center"
      VerticalOptions="Center">
</Grid>

The Grid itself is defined in XAML, but its rows, columns and contents will be created using C#.

CreateTheGrid that takes as input one variable num

The method should:

  2. Add three ColumnDefinition objects to GameGrid.

You have already seen how to add a row or column to a Grid.

For example, the following adds one row:

And this adds one column:

Start Button

Add a Button to your XAML:

<Button x:Name="StartButton"
        Text="Start Game"
        Clicked= />

Create the appropriate event handler. Remember what I said in lectures about using Visual Studio to create the event handler, try to do that otherwise you will need to write the signature yourself.

When the button is clicked, it should call your CreateTheGrid(3) method.

This means the entire contents of the event handler is:

private void EventHandlerName(object sender, EventArgs e)
{
    CreateTheGrid(3);
}

Aside: Why not put the grid code in the Event Handler?

The question you are probably asking is, why not just put the contents of CreateTheGrid directly into the event handler?

It is good programming practice to keep methods focused on a particular task: - The event handler deals with the event - in this case the user clicking the button. - CreateTheGrid deals with creating the grid.

This also means that CreateTheGrid does not care why it was called. It could be called from this event handler, from another method, or later when we want to create a different-sized board.

Keeping tasks in separate methods makes code easier to understand, reuse and change.

Creating the Game Squares

A Grid does not automatically draw lines around its cells.

We need to put something inside each cell.

We are going to use Border objects.

A Border can be created in C#:

Border border = new Border
{
    BackgroundColor = Colors.Red,
    Stroke = Colors.Black,
    StrokeThickness = 2
};

A Border can then be added to a particular Grid cell.

For example:

GameGrid.Add(border, column, row);

Remember that Grid positions are zero-indexed.

The top-left cell is:

row = 0
column = 0

The centre cell is:

row = 1
column = 1

The bottom-right cell is:

row = 2
column = 2

Use nested loops.

  • What should the outer loop represent?
  • What should the inner loop represent?
  • Where should row come from?
  • Where should column come from?
  • When should a new Border be created? The above code creates one border.

Adding a Tap Gesture

We now need to allow the player to select a square.

A Border can have a gesture recogniser attached to it.

Create a TapGestureRecognizer:

TapGestureRecognizer tapGestureRecognizer = new TapGestureRecognizer();

The Tapped event can be subscribed to in the usual way:

tapGestureRecognizer.Tapped += OnBorderTapped;

The recogniser then needs to be added to the Border:

border.GestureRecognizers.Add(tapGestureRecognizer);

Task

Add a TapGestureRecognizer to every Border that you create.

Create an event handler called:

OnBorderTapped

Use the appropriate event arguments for a tap gesture. You may be able to get Visual Studio to create this automatically for you.

When a Border is tapped, temporarily change its background colour.

For example:

You will need to work out how to obtain the Border that was tapped from sender. See the lecture notes!

Keeping Track of the Board

There is currently a problem.

A player can select the same square more than once.

We need to keep track of which squares have already been used.

Create a two-dimensional array:

private int[,] positions;

A value of:

  • 0 means the square is empty
  • 1 means Player 1 has used it
  • 2 means Player 2 has used it

Create the array when you create the game board.

You need a 3 × 3 array.

Task

Task

  3. If it is 0, make the move.

  5. Change the player.
  6. If the square is already occupied, do nothing.

Checking for a Winner

The game now works, but it doesn’t know when somebody has won.

Create a method:

CheckWinner

It should take the player number and return an integer.

Use these return values:

Return value Meaning
0 No winner yet
1 Player 1 wins
2 Player 2 wins
3 Draw

A player wins if they have completed:

  • an entire row
  • an entire column
  • the diagonal from top-left to bottom-right
  • the diagonal from top-right to bottom-left

Task

Write CheckWinner().

You will need to examine the positions array.

Think about how you could use loops to avoid unnecessarily repeating code.

You may find it useful to break the problem into smaller methods.

private static bool SearchDiagonalComplete(int[,] ints, int size, int which)
{
    //Top left to bottom right
    bool foundit = true;
    for (int i = 0; i < size; i++)
    {
        if (ints[i, i] != which)
        {
            foundit = false;
            break;
        }
    }
    if (foundit)
        return true;
    //Top right to bottom left
    foundit = true;
    for (int i = size - 1; i >= 0; i--)
    {
        if (ints[i, size - 1 - i] != which)
        {
            foundit = false;
            break;
        }
    }
    if (foundit)
        return true;
    return false;
}

{

private static bool FindinArray(int[,] ints, int size, int which)
{
    bool foundit = false;
    for (int i = 0; i < size; ++i)
    {
        for (int j = 0; j < size; j++)
        {
            if (ints[i, j] == which)
            {
                foundit = true;
                break;
            }
        }
        if (foundit)
            break;
    }
